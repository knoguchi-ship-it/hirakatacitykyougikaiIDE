## 4. DB Schema Changes

T_役員 / T_振込口座 / T_請求 に `職員ID`（null 可）を追加。

## 6. Known Bug（最優先修正）

**振込口座管理タブで事業所職員役員の口座登録・確認ができない**

- **場所**: `src/components/OfficerManagement.tsx` の `BankAccountTab`
- **症状**: 事業所職員の役員を選択すると `（）` と空の番号で表示され、口座操作ができない
- **原因**: dropdown の `value` が `o.会員ID` のため、職員型役員では空文字になる
- **影響**: `getBankAccount_({ memberId: '' })` が呼ばれ口座取得不能
- **修正方針**: `personKey = o.職員ID || o.会員ID` を key に使い、`loadAccount` 時に `staffId` か `memberId` を適切に渡す

詳細は §7（修正手順）参照。

## 7. Bug Fix Guidance（振込口座タブの事業所職員対応）

### 現状コード（BankAccountTab）

```tsx
// activeOfficers の map（問題箇所）
<option key={`${o.役員ID}`} value={o.会員ID}>
  {o.表示名}（{o.会員ID}）
</option>
```

### 修正方針

```tsx
// 1. personKey = 職員ID が存在すれば職員ID、なければ会員ID
const personKey = o.職員ID || o.会員ID;

// 2. option の value を personKey に変更
<option key={o.役員ID} value={`${o.職員ID ? 'staff:' : 'member:'}${personKey}`}>
  {o.表示名}（{personKey}）
</option>

// 3. handleSelectMember で prefix を解析して staffId/memberId を分離
const handleSelectMember = (value: string) => {
  setSelectedPersonKey(value);
  const isStaff = value.startsWith('staff:');
  const id = value.replace(/^(staff|member):/, '');
  const staffId = isStaff ? id : '';
  const memberId = isStaff ? '' : id;
  // loadAccount({ memberId, staffId }) で呼び出す
};

// 4. api.getAdminBankAccount / saveAdminBankAccount に staffId を渡す
await api.getAdminBankAccount({ memberId, staffId });
```

### api.ts の変更

`getAdminBankAccount` / `saveAdminBankAccount` / `deleteAdminBankAccount` の型に `staffId?: string` を追加し、payload に含めるよう変更。
