# v376.97 リリース状態（2026-09-22）

## 1. 結論

管理画面「システム設定 ＞ メール通知」の「メール通知の内容」を、系統を選んでからその系統のカードだけを表示する形にした。14 枚のカードを一度に並べていたため画面が長く、目的の設定に届くまでスクロールが必要だった。

配信状態を選ぶ「メール配信」（停止／通常送信／テスト集約）は、独立したセクションのまま残した。配信状態は系統に依存しないため。

バックエンドの変更はない。設定値・保存形式・送信挙動は変えていない。

## 2. 変更内容

- 「メール通知の内容」の先頭に系統選択ボタン（`MailCategoryPicker`）を置いた。系統は v376.96 で定めた 6 つ（入会申し込み／職員追加／申請ワークフロー／研修／会員手続き／認証・セキュリティ）。
- ボタンに「n 件中 m 件が有効」「n 件すべて停止中」を表示し、開かなくても止まっている系統が分かるようにした。
- 未選択のボタンもカテゴリ色のアイコンを保つ。灰色にすると色で系統を見分けられなくなるため、選択の有無は枠線とリングで示す。
- 系統を切り替えても入力値は保持し、保存は従来どおり画面下の一括保存でまとめて行う。その旨を説明文に明記した。
- 送信元アドレスは全系統に共通なので常時表示する。入会・登録メールの共通スイッチと `MasterOffBanner` は、それが効く入会・職員追加の系統でだけ表示する。

一度に表示されるカードは最大 14 枚から 3 枚になった。

## 5. GCP 移植メモ

系統選択は表示層だけの関心事であり、Cloud Run 側の通知アダプタには影響しない。系統の定義と配色は `src/shared/mailCategories.ts` に集約しているため、移植時はこのファイルと `MAIL_CATEGORY_ORDER` の並び順をそのまま持ち込む。

## 6. 運用上の申し送り

1. 表示のみの変更で、メール設定値・送信挙動には触れていない。配信状態は v376.95.1 のまま。
2. 系統選択の状態は画面を離れると既定（入会申し込み）に戻る。保存対象ではない。
3. 「Google Chat」タブと他のシステム設定タブには、この系統選択を適用していない。横展開するかは別途判断する。
