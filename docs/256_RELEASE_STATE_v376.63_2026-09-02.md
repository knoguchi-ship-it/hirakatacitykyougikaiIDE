## 2. 決定した運用ルール（正本 = `AGENTS.md`）

### 2.1 §4.7 開発拠点（保守モード解除）

- 本リポジトリは**通常開発モード**。新規機能追加・改修を通常のリリースフローで受ける。
- ただし GAS へ write 系を足すと `docs/250` §6.1 の未移行 write（66 method）が増えるため、
  **大型の新規 write 機能は着手前に「GAS/GCP のどちらで作るか・二重実装の工数」を operator に提示して方針確認する**。
  小〜中規模・障害修正・運用要求は確認不要。
- 完了条件（prerelease 全ゲート → 3 split 生成物 grep → 4 本同期 → live E2E → 正本更新）は従来どおり必須。
- 凍結（変更禁止）判断は `docs/250` §5 Phase 6 の旧 URL 転送化と同時に行う（今回の解除とは別軸）。

### 2.2 §4.4 画面表示は日本語を既定とする

1. 装飾目的の英語を置かない（見出し上の英字ラベル等）。
2. 日本語で言えるものは日本語にする（`allowlist`→許可リスト、`ON/OFF`→有効／無効）。
3. 英字を使ってよいのは ①内部値・識別子をそのまま示す必要があるとき（`LIVE` / `REDIRECT` / `SUPPRESS`、シート列名、ID、URL）
   ②日本語化するとかえって通じない定着語（Excel / PDF / CSV / Drive / LINE 等）。①では**日本語を主・英字を従**とする。
4. 日本語見出しに `uppercase tracking-wide` を当てない。
5. 新規画面・改修時もこの規約に反する文字列を残さない。
