# Release State v303

作成日: 2026-05-04
対象版番: `v303`

## 1. Scope

`v302` で会員管理コンソールの事業所職員一覧を `T_事業所職員` 由来の `staffRows` で表示するよう修正したが、Apps Script `CacheService` に旧 `adminDashboard` cache が残っている場合、`staffRows` を含まない cached response が返り、反映直後に一覧が空のまま残る可能性があった。

`getAdminDashboardData_()` で cached response を返す条件を `cached && cached.staffRows` に変更し、旧形式 cache は無視して再生成するよう修正した。
