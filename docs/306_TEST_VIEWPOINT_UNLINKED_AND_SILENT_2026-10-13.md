# 306 「表示されているのに結び付いていない」「黙って失敗する」— テスト観点表と全体調査（2026-10-13）

## 0. この文書の目的

`docs/305` のテスト中に見つけた不具合を「種類」に分けて観点にした。
そのうえで、**システム全体に同じ種類の不具合が無いか**を調べ、修正計画を立てる。

operator の原則（2026-10-13）:
> 紐づいていないことは意味のないこと。そして、画面上に表示されていると、紐づいていると勘違いをする。

この観点表は、今後の新機能・改修のテストでも使う。

## 1. 観点表

検出方法は 3 つある。
- **機械**: 構文解析・検査スクリプト。全数を数えられる
- **画面**: Playwright で実画面を開いて数える・操作する
- **読解**: コードを読んで判断する。漏れがありうるので、見つけたものは画面か実行で確かめる

## 3. 修正計画

### 3.0 進め方

- 段階ごとに「直す → 修正前のコードで落ちる検査を足す → 画面で確かめる → リリース」を繰り返す。1 回のリリースを大きくしない。
