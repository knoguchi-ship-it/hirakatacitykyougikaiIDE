## 2. 背景

v373.3 で「条件付き書式」の演算子 UI を簡素化したが、操作者の実機検証で **行フィルタ（出力対象の絞り込み）にも同じ問題**が残っていることが判明。`=`, `>`, `<`, `≥`, `≤`, `範囲`, `空`, `空でない`, さらに「否定」「いずれか」トグルなど、プログラマ前提の演算子記号が UI に並んでいた。

ユーザー要件: **「演算子の概念ごと UI から消す。フィールド型ごとに最適なシンプル UI を提供する」**

## 3. 修正内容

### 3-1. 行フィルタ専用 operators を新設（`FILTER_OPERATORS_BY_TYPE`）

記号を全て日本語ラベルに置換し、よく使わない演算子を削除して 3〜6 個に絞り込み:

| 型 | 採用 operators | 廃止 |
|---|---|---|
| string | 含む / 入力あり / 空欄 | 等しい / 始まる / 終わる / 含まない |
| number | ぴったり一致 / 以上 / 以下 / 範囲 / 入力あり / 空欄 | `=` `>` `<` `≥` `≤` の記号化、ぴったり一致以外の厳密比較 |
| date | 以前 / 以降 / 期間 / 入力あり / 空欄 | `=` の記号化 |

### 3-2. フィールド型ごとに最適な UI 分岐

| 型 | UI |
|---|---|
| **enum**（郵送先区分・年会費納入状況 等） | **演算子 select を撤廃。値チェックボックスのみ**。チェック = 含める / 未チェック全部 = フィルタなし |
| **boolean** | **演算子 select を撤廃。3 ラジオ**（指定なし / はい / いいえ） |
| **string / number / date** | 演算子（日本語ラベル）+ 値入力 |
| **年度 picker**（年会費対象年度） | **行フィルタ UI 全体を非表示**。画面上部の「在籍判定年度」で既に絞られているため冗長 |
| **formula / literal 列** | 行フィルタ UI を非表示（フィルタ対象として意味がない） |

### 3-3. 否定トグル完全廃止

- 行フィルタからも否定ボタンを撤去（v373.3 では条件付き書式のみ廃止していた）
- `negate` プロパティは型定義に残し、`evalRowFilter` も legacy 互換のため反転処理を維持。新規入力経路だけ閉鎖

### 3-4. `operatorLabel()` の更新

active filters chip 表示が、新しい日本語ラベル（`FILTER_OPERATORS_BY_TYPE`）を優先して引くように更新。legacy 記号付きの operator も既存データ表示用に fallback 維持。

## 4. UX 比較

### Before (v373.3)

```
[条件: ▼(なし)]  [(なし) / = / > / < / ≥ / ≤ / 範囲 / 空 / 空でない]
                  (※ 演算子記号でプログラマ前提)
[○否定]  [値: ___]
```

### After (v373.4)

#### 文字列 / 数値 / 日付
```
[絞り込み: ▼(なし)]  [(なし) / 含む / 入力あり / 空欄]  (※ 全て日本語)
[値: ___]
```

#### enum（郵送先区分）
```
[絞り込み: 該当を選択（未選択=全件）]
[☐ 勤務先]  [☐ 自宅]
```

#### boolean
```
[絞り込み: ●指定なし  ○はい  ○いいえ]
```

#### 年度フィールド
```
（行フィルタ UI は表示しない。画面上部の「在籍判定年度」で絞り込み済み）
```

1. admin shell をリロード（@150）
2. 「年会費納入状況」列で行フィルタ → **演算子 select が消え、`☐ 納入済み` `☐ 未納` のチェックボックスのみ** が表示されることを確認

## 8. 後方互換

- 既存テンプレに保存されている `equals` (string) / `gt` / `lt` / `gte` / `lte` などの operator は **評価器が引き続き処理**。ただし UI から編集すると新型 operators に倒れる
- 既存テンプレの `negate: true` は **評価時に反転処理される**（読取専用）
- 既存テンプレの `notContains` / `notEquals` / `notIn` などの legacy operator も `operatorLabel()` でラベル表示可
