# Release State v320

作成日: 2026-05-11
対象版番: `v320`

## 概要

スマートフォンで「白ページになり表示されない」問題への対応として、全 3 Apps Script プロジェクトの `doGet()` に server-side viewport meta（`addMetaTag`）を追加。さらに公開ポータルを mobile-first レスポンシブ UX に強化。AGENTS.md にレスポンシブ必須グランドルールを追加。

## 根本原因

GAS Web App は外側 iframe（`script.googleusercontent.com`）で配信される。HTML ファイル内の `<meta viewport>` は外側ラッパーに伝播せず無視される仕様（Google 公式 doc 明記）。viewport が `width=device-width` にならないため、モバイルでページが極端に縮小されるか描画失敗し、白ページに見えていた。

修正方法は server-side で `HtmlOutput#addMetaTag('viewport', ...)` を呼ぶこと。

## 変更内容

### 1. P0: viewport / theme-color の server-side 追加（3 プロジェクト）

各 `doGet()` 内、`HtmlService.createHtmlOutputFromFile(...)` のチェーンに以下を追加:

```js
.addMetaTag('viewport', 'width=device-width, initial-scale=1, viewport-fit=cover')
.addMetaTag('theme-color', '#0369a1');
```

対象ファイル:
- `gas-src/Code.full.gs`（→ `backend/Code.gs` を生成）
- `gas/admin/Code.gs`
- `gas/member/Code.gs`

`viewport-fit=cover` は iPhone ノッチ・Dynamic Island 対応。`theme-color` はモバイルブラウザのアドレスバー色を統一しブランド一貫性を向上。

### 2. P1: 公開ポータル mobile-first レスポンシブ UX

`src/public-portal/App.tsx`:

- ルート: `min-h-screen` → `min-h-[100dvh]`、`overflow-x-hidden` を追加（iOS Safari アドレスバー高変動・横スクロール防止）
- ヘッダー/フッター: `flex` を狭幅で縦積み（`flex-col sm:flex-row`）に変更
- ヘッダー H1: `text-base sm:text-lg md:text-xl`（段階的）
- ヒーロー H2: `text-2xl sm:text-3xl md:text-4xl`
- メニューカード grid: `md:grid-cols-2` → `sm:grid-cols-2`（タブレット縦持ち以上で 2 列化）
- カード padding/角丸: `p-7 rounded-[28px]` → `p-5 rounded-[20px] sm:p-7 sm:rounded-[28px]`
- 戻るボタン: `min-h-[44px]` 追加（WCAG 2.2 / Apple HIG タップターゲット）
- 「全カード無効」メッセージ: `col-span-2` → `sm:col-span-2`

### 3. グランドルール追加（AGENTS.md §4）

「**レスポンシブ対応は必須機能**」項を新設。以下を完了条件化:
1. GAS server-side viewport（3 プロジェクト全 doGet）
2. Mobile-first レイアウト（unprefixed → sm: → md:）
3. WCAG 2.2 / Apple HIG タップターゲット 44×44px
4. 横スクロール禁止
5. `min-h-[100dvh]` / `min-h-svh` 使用
6. WCAG 2.2 §1.4.10 リフロー（320px・200% ズーム）
7. モバイル幅 360–414px での表示・操作確認
