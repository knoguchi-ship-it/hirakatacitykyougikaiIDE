## 5. 重要な学び（次担当者がハマらないために）

### GAS HtmlService の落とし穴
- `addMetaTag()` の `name` 引数は **`viewport` / `apple-mobile-web-app-capable` / `mobile-web-app-capable` / `google-site-verification` の 4 種のみ**。`theme-color` 等を渡すと WebApp 全体が `Exception: 指定したメタタグはこのコンテキストでは使用できません` で停止する（v320 → v321 hotfix の経緯）。
- HTML 内の `<meta viewport>` は外側 iframe ラッパーで無視される。**server-side `addMetaTag` が唯一の正解**。
- React アプリは 3 重ネスト iframe の最深部に描画される。URL は `/blank` で終わる（`/userCodeAppPanel` ではない）。フレーム検出は本文内容ベースが堅牢。

### iOS Safari の vh 落とし穴
- `90vh` などの `vh` 単位はアドレスバー収納時の最大値を基準にする。アドレスバー表示時はモーダルフッターが画面外に出る → **`dvh` / `svh` を使う**。
- セーフエリア対応: `pb-[max(1rem,env(safe-area-inset-bottom))]`。

### `unsupported_action` / `member_unauthorized` の典型原因
- `unsupported_action`: アクションが 3 種のレジストリ（PUBLIC / MEMBER / ADMIN）いずれにも未登録。`MEMBER_ALLOWED_ACTIONS` / `ADMIN_ACTION_PERMISSIONS` / `PUBLIC_ALLOWED_ACTIONS` を確認。
- `member_unauthorized`: 会員向けアクションを呼ぶ際に `sessionToken` が payload に無い。`src/services/api.ts` で `memberSessionPayload()` の付与漏れを確認。

### 文字コード
- Markdown / HTML / text 系は UTF-8 で保存。PowerShell の `Set-Content` 既定（UTF-16 LE BOM）に注意 → `-Encoding utf8` を明示。
