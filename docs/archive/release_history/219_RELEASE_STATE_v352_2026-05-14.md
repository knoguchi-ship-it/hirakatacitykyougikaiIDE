# Release State v352

Date: 2026-05-14
Status: production deployed (integrated/public のみ更新)

## Scope

公開ポータルの「現在受付中の研修」一覧 (`src/public-portal/components/PublicTrainingList.tsx`)
を A4 縦の PDF サムネイル付き 2 カラムカードへ再設計した。ユーザー要望:

> 該当する研修の画像を A4 縦で表示。その画像をクリックすることで、該当のPDFが開く。
> 研修の日時・場所・主催者など、登録されている情報はちゃんと見えるように。

を `PdfThumbnail` の最小拡張 + `PublicTrainingList` の完全書き換えで実現。

## Web 検索で採用した設計判断

| 観点 | 採用 | 出典 |
|---|---|---|
| カード UI の tab 順 = HTML 順、冗長リンクは可だが意味的に並べ替えると better | 画像とテキストリンクを縦隣接で配置 | [UC Berkeley DAP accessible card patterns](https://dap.berkeley.edu/web-a11y-basics/accessible-card-ui-component-patterns) |
| WCAG 2.5.5 タップターゲット 44×44px / リンクテキスト 3:1 contrast | CTA / リンクすべて `min-h-[44px]` で確保 | [WCAG 2 2026 update](https://ixdf.org/literature/topics/web-content-accessibility-guidelines) |
| 小サイズで読みやすい構図 | 概要 / メタ情報を grid 2 列で密度高く表示 | [Aspect Ratios 2026 explained](https://blog.freeimages.com/post/aspect-ratios-2026-explained-3-2-4-3-1-1-16-9-crop-guide) |
| Semantic HTML (article / header / h2 / dl) | 採用 | 同上 + Liberogic 2026 ガイド |
| A4 縦比 = 210 / 297 (≈ 1:1.414) | `aspect-ratio: 210 / 297` CSS で物理紙比固定 | ISO 216 標準 |

## Implementation

### `src/components/PdfThumbnail.tsx`
- `aspectRatio?: string` prop を追加（例: `'210 / 297'`）
- 指定時は `height` を無視して `width: 100%` + `aspect-ratio` のスタイルを適用
- 既存呼び出し（member `TrainingApply`, admin `TrainingManagement`）は `height={n}` パスのまま挙動不変

### `src/public-portal/components/PublicTrainingList.tsx`
- セマンティック `<article>` + `<header>`（受付中バッジ + 開催日時）
- `sm+` で 2 カラム / mobile は縦並び
- **左カラム**: `PdfThumbnail` を `aspectRatio="210 / 297"` で A4 縦表示、`max-w-[180px] sm:max-w-[200px]`。下に「案内PDFを全ページ開く」テキストリンク（44px 確保、サムネイルと同じ destination だがキーボード/SR 経路として残置）
- **右カラム**: H2 タイトル → 概要 → メタ情報 `<dl>` (開催日時 / 会場 / 主催 / 講師 / 定員 / 申込締切) → 詳細内容 → 参加費 → 問合せ先 → `mt-auto` で右下に「申し込む」CTA
- `thumbnailUrl` 空時は A4 比の placeholder ("案内PDFサムネイル未生成") を出して情報パネルは通常表示。申込フロー自体は阻害されない
- すべての CTA / リンクに `aria-label` と `min-h-[44px]`

## Operator residual checks

1. 公開ポータルにアクセス → 「現在受付中の研修」一覧を表示
2. 各研修カードで:
   - A4 縦サムネイル（紙の縦横比）が左/上に表示
   - サムネイルをクリック → 案内 PDF が新タブで開く
   - 開催日時 / 会場 / 主催 / 講師 / 定員 / 申込締切 が右/下に明確に表示
   - 「案内PDFを全ページ開く」テキストリンク（サムネイル下）も同じ PDF を開く
   - 「申し込む」ボタン（右下） → 既存申込フローへ遷移
3. **モバイル幅 (360-414px)** で 1 カラム縦並びになり、A4 サムネイルが画面幅 max 180px で中央寄せされていること
4. **大きい viewport (1280px+)** で 2 カラム、サムネイル 200px + 右に情報パネル
