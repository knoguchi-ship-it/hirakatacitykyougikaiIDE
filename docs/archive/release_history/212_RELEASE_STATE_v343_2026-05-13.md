# Release State v343

Date: 2026-05-13
Status: production deployed

## Scope

- Admin console "登録済み管理者アカウント" 一覧の「表示名」列が、事業所職員紐付けの場合に
  権限ラベル（「マスター」「管理者」など）だけになっていた事象を修正。
- `getAdminPermissionEntries_` が `memberMap[linkedMemberId]` だけを参照していたため、
  `T_認証アカウント.職員ID` 経由で紐付いた事業所職員の氏名が取れず、`derivedDisplayName`
  が権限ラベル単体になっていた。`staffMap[linkedStaffId]` も参照し、`氏名` または
  `姓+名` を取り出して `氏名（権限）` 形式へ統一。
- 個人会員紐付け側の挙動は不変（既存ケースを `memberRow` 経路で優先）。
- 公開ポータル / 会員マイページの artifact には影響なし（`getAdminPermissionEntries_` は
  admin 専用関数で boundary build 時に pruning される）。

## Code-level verification

- 修正は `gas-src/Code.full.gs` 一箇所。`build:gas:admin` で `gas/admin/Code.gs` に
  反映されたことを確認（`grep staffRow = staffMap[linkedStaffId]` が admin artifact
  のみヒット）。
- `npm run prerelease` PASS（audit / public-boundary / member-boundary / admin-boundary /
  typecheck）。
- public artifact (`backend/Code.gs`) と member artifact (`gas/member/Code.gs`) は
  byte 単位で不変（git status に変化なし）。
