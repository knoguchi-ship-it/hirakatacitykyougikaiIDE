# v376.94 リリース状態（2026-09-15）

## 1. 結論

賛助会員の会員情報変更申請を承認すると、賛助会員用の自動採番ログインIDを介護支援専門員番号として誤って補完し、8桁検証で承認に失敗する不具合を修正した。

## 2. 修正内容

- 賛助会員ではログインIDを介護支援専門員番号の代替値に使用しない。
- 賛助会員の介護支援専門員番号は任意とし、連絡先等の変更承認時に必須・8桁書式検証しない。
- 既存レコードに任意の値がある場合は保持し、空欄のときは空欄のままとする。
- 個人会員の介護支援専門員番号必須・書式検証、および事業所会員の既存運用は変更しない。
