# Release State v347

Date: 2026-05-14
Status: production deployed

## Scope

会員マイページ・公開ポータル・管理者ポータルで案内 PDF サムネイル画像が表示されない
事象（v344 / v345 / v346 でも未解消）について、本番ログから真因を再再確定して
`getFileThumbnail_` を Drive REST API v3 ベースに書き換えた。

## 失敗履歴と最終真因

| 版 | アプローチ | 失敗理由 |
|---|---|---|
| v272 | `DriveApp.getFileById(id).getThumbnail()` | PDF に対し常に null（Apps Script 既知制約） |
| v344 | client を v272 proxy 経由に配線 | サーバー側 API が PDF 非対応のままだった |
| v345 | `UrlFetchApp('drive.google.com/thumbnail?id=...')` 匿名 | Google reCAPTCHA で 403 |
| v346 | 同 endpoint に `Authorization: Bearer <token>` 付与 | **本番ログで `code=403 fileId=...` を確認**。drive.google.com/thumbnail は Authorization 付きでも PDF を拒否する。 |
| **v347** | **Drive REST API v3 `files.get?fields=thumbnailLink` → `lh3.googleusercontent.com/...` を Bearer 付きで fetch** | Drive の Web UI と同じ render pipeline が裏で thumbnailLink を埋めるため PDF にも対応。 |

## 修正内容（`gas-src/Code.full.gs:getFileThumbnail_`）

```javascript
// Step 1: file metadata から thumbnailLink を取得
var metaUrl = 'https://www.googleapis.com/drive/v3/files/' + encodeURIComponent(fileId) +
  '?fields=thumbnailLink%2Cname%2CmimeType&supportsAllDrives=true';
var metaResp = UrlFetchApp.fetch(metaUrl, {
  muteHttpExceptions: true,
  headers: { Authorization: 'Bearer ' + ScriptApp.getOAuthToken() },
});
// ... thumbnailLink 取り出し

// Step 2: thumbnailLink (lh3.googleusercontent.com/...) から bytes 取得
var sizedLink = thumbnailLink.replace(/=s\d+(-.+)?$/, '=w400').replace(/=s\d+$/, '=w400');
var imgResp = UrlFetchApp.fetch(sizedLink, {
  muteHttpExceptions: true,
  followRedirects: true,
  headers: { Authorization: 'Bearer ' + ScriptApp.getOAuthToken() },
});
// → base64 化して data: URL で返却。CacheService 1h TTL（95KB 上限）。
```

- 既存 `drive` scope（3 境界とも `appsscript.json` に設定済み）で動作。追加 OAuth 再承認不要。
- `thumbnailLink` の `=s220` などサイズ指定を `=w400` へ差し替えて視認性を向上。
- 失敗時の Logger には HTTP code・fileId・mimeType を残し、原因切り分けを容易にした。

## clasp 認証メモ

v346 → v347 の deploy 途中で Google Workspace の reauthentication ポリシーにより
`invalid_grant` / `invalid_rapt` が発生。`npx clasp login` で再認証後に redeploy 完了。
push と version は再認証前に成功していたため、Apps Script 側にコードは既に上がって
いた状態だった。今後同種事象では `npx clasp login` だけで復旧可能。

## Residual checks (operator-side)

1. 会員マイページの研修詳細（申込済み研修の「添付PDF」セクション）でサムネイル画像が
   実際に表示されること。「PDF プレビューを読み込めませんでした」が消えること。
2. 公開ポータルの研修一覧でも同様に表示されること。
3. 管理者ポータル研修管理の編集モーダルでも同様に表示されること。
4. Apps Script Executions で次のいずれの警告も出ていないこと:
   - `getFileThumbnail_ files.get non-200: ...`（Drive REST 認証/権限エラー）
   - `getFileThumbnail_ thumbnailLink absent for fileId=...`（PDF が共有未公開等で
     Google 側が thumbnailLink を生成していない）
   - `getFileThumbnail_ thumbnailLink fetch non-200: ...`（短命 URL の失効 等）
   いずれかが出る場合、ファイル単位の権限・共有設定を確認する。
