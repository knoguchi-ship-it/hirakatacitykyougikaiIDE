# v376.96 リリース状態（2026-09-18）

## 1. 結論

管理画面「システム設定 ＞ メール通知」の設定カードを、カテゴリごとに色分けした。14 枚のカードがすべて同じ紫で、文字を読まないとどの設定かを判別できない状態を解消した。

あわせて、内容が雑多だった「その他の自動通知メール」1 グループ 6 枚を、研修 / 認証・セキュリティ / 会員手続き の 3 グループへ分割し、全体を 6 グループ 14 枚に整理した。

バックエンドの変更はない。設定値・保存形式・送信挙動は一切変えていない。

## 2. 設計

この画面には独立した 2 つの情報がある。

| 情報 | 変更前 | 変更後 |
|---|---|---|
| A: どの種類のメールか | 文字のバッジのみ（色は 14 枚とも同じ紫） | **色相**（6 色）＋ **アイコンの形** |
| B: 有効か無効か | 紫 / グレー | **色の有無**（色付き＝有効、グレー＝無効） |

色というチャネルに B しか載っておらず、A が文字だけだったことが「見分けがつかない」原因だった。チャネルを分けて割り当て、色・形・文言の 3 重符号化により色だけに依存しない（WCAG 1.4.1）。

### カテゴリと色

| グループ | 色 | カード |
|---|---|---|
| 入会申し込み時のメール | emerald | 個人・賛助会員 / 事業所・代表者 / 事業所・メンバー |
| 職員追加申請 承認時のメール | sky | 追加職員 / 代表者通知 |
| 変更申請ワークフローのメール | amber | ①受付確認 / ②承認通知 / ③却下通知 |
| 研修のメール | indigo | 研修申込確認 / 研修リマインダー |
| 認証・セキュリティのメール | rose | 公開ポータルOTP / パスワード再設定 |
| 会員手続きの確認メール | violet | 会員情報変更確認 / 退会申請受付 |

当初は研修を teal にしたが、実ビルドの CSS で描画して確認したところ入会（emerald）と緑系で近すぎたため indigo へ変更した。

## 3. 実装内容

- `src/shared/mailCategories.ts` を新設し、カテゴリ 6 種の配色を正本化した。
  **Tailwind v4 はクラス名を動的に組み立てても CSS を生成しない**ため、完成形のクラス文字列だけを表に持ち、利用側で文字列を結合しない。
- バッジは各色の 100 番background に 800 番foreground を使い、コントラスト比 4.5:1 以上を満たす組み合わせだけを採用した。
- `EmailCard` に `category` prop を追加し、左端 `border-l-4` のカラーバー、カテゴリ色バッジ＋アイコンを付けた。無効時はカテゴリ色を抜いて「停止中」を表示する。
- `MailGroupHeader` を追加し、従来の細い `<h4>` ＋ 罫線を、色帯 ＋ アイコン ＋ 件数の見出しへ置き換えた。
- グループ見出しの sticky 追従は採らない。`AdminSettingsSection` が `overflow-hidden` を持つため sticky が機能しないため、帯の強調で代替した。
