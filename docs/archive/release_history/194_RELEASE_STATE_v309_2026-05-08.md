# Release State v309

作成日: 2026-05-08
対象版番: `v309`

## 1. Scope

年会費管理コンソールに、管理者全員で共有できる申し送りメモパネル（ホワイトボード型）を追加した。

- MASTER / ADMIN は書き込み可。それ未満の権限は閲覧のみ（現状コンソール自体が ADMIN+ 限定）。
- 60 秒ごとの自動ポーリングと「↻ 今すぐ更新」ボタンによる即時更新を実装。
- 楽観的排他制御（バージョン番号管理）により、複数管理者の同時編集時に競合バナーを表示。
- DB に `T_共有メモ` シートを新規追加（初回 saveSharedMemo_ 呼び出し時に自動作成）。

## 2. テーブル追加

### T_共有メモ（新規）

**追加場所: `gas-src/Code.full.gs` の `テーブル定義` ブロック末尾（`T_請求` 定義の直後）**

| 列名 | 内容 |
|---|---|
| `キー` | ボード識別子（`ANNUAL_FEE_BOARD` 固定） |
| `内容` | メモ本文 |
| `更新者メール` | 最終更新者の Google アカウントメール |
| `更新者名` | 最終更新者の表示名 |
| `更新日時` | ISO 8601 形式 |
| `バージョン` | 楽観的排他制御用整数 |

**シート作成方法（2通り）**

- 自動: 初回 `saveSharedMemo` API 呼び出し時に `saveSharedMemo_()` が自動作成。
- 手動: Apps Script エディタ（admin split）から `runAddSharedMemoSheetForV309()` を実行。

**`runAddSharedMemoSheetForV309()` の場所: `gas-src/Code.full.gs` 末尾（ファイル最終行付近）**
