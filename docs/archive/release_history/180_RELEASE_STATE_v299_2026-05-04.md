# Release State v299

作成日: 2026-05-04
対象本番: `v299`

## 1. Scope

管理者ポータルの会員管理コンソールに、事業所会員を探しやすくする「事業所会員」ビューを追加。

- 既存の `members` state と `adminDashboardData.memberRows` から表示専用データを派生。
- タブ切替、検索、ページングでは GAS API を呼ばない。
- 検索対象は事業所番号、事業所名、代表者、職員名、職員メール、CM番号、電話番号。
- 代表者不在、メール未設定、事業所番号なしを一覧上で確認可能。
- 行クリックは既存の会員詳細画面へ遷移し、編集・保存 API は既存導線を維持。
