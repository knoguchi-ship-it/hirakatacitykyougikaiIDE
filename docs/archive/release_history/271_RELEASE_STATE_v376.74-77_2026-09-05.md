## 1. やったこと

会員種別を選んだ直後に、**種別ごとの注意事項を読ませるステップ**を設けた。
文面は既存の `T_規程`（規程・重要事項マスタ）を正本とし、**管理画面から項目単位で追加・編集・削除**できる。

```
① 会員種別 → ② 注意事項 → ③ 基本情報 / 事業所情報 → ④ 住所・連絡情報 / 職員登録 → ⑤ 入力確認
```

②の構成:

```
事務局からのお願い（ご入会にあたって）        ← 全種別共通（対象 ALL）
  ■ 入会について / ■ 会費について / ■ 退会の手続きについて
  個人情報の利用目的 / 協議会の定款
──────────────────────────────
▼ 個人会員について                        ← 種別ごと（折りたたみ・初期は閉じた状態）
  ■ 年会費について
  ■ 住所変更等された場合の手続きについて

☑ 上記の注意事項（全体および会員種別ごと）を確認し、内容を理解しました。
```

## 2. 設計の判断

### 新テーブルを作らず `T_規程` を使う

`T_規程` には既に `対象会員種別`（`ALL` / `INDIVIDUAL` / `BUSINESS` / `SUPPORT`）があり、
管理画面の CRUD も揃っていた。**同じ役割の入れ物を 2 つ作らない**（`AGENTS.md` §3）。

### 種別選択のゲートを廃止し、確認を②へ移した

従来は種別を選ぶ**前**に「重要事項を確認する」ダイアログを開かせ、チェックするまで種別カードを
`disabled` にしていた。**種別ごとの案内は種別が決まらないと出せない**ため、ゲートを②へ移した。
ダイアログの中身は見た目ごと②の上段へ移している（operator 指示・「スライドするだけのイメージ」）。

### 会費は本文に書かず差し込みタグにする

会費の正本は `M_会員種別.年会費金額`。本文に金額を書くと**会費改定のたびに文面も直す**ことになり
二重管理になる。`{{年会費}}` などのタグを表示直前に置き換える（`src/shared/regulationText.ts`）。
未対応のタグは空文字にして `{{...}}` のまま利用者へ見せない（メール本文と同じ方針）。

| タグ | 置き換わる内容 |
|---|---|
| `{{年会費}}` | 選択中の種別の年会費 |
| `{{会員種別}}` | 選択中の種別名 |
| `{{個人会費}}` `{{事業所会費}}` `{{賛助会費}}` | 種別を指定した年会費（他種別へ言及する文面のため。現在は未使用） |

### 共通に寄せられるものは共通へ（v376.75）

v376.74 では種別ごとに 15 項目を入れたが、共通側と内容が重複し②が縦に長くなった。
**「全種別に等しくかかること」を共通へ、種別ごとは「その種別でしか言えないこと」だけに**した。

| 共通へ移した | 理由 |
|---|---|
| ■ 入会について | 3 種別で対象の呼び方しか違わなかった |
| ■ 会費について（返還不可・郵便局振込） | 種別に依らない |
| ■ 退会の手続きについて | 同上 |

既存の共通 3 件（会費の返還について / 退会の締切 / 変更・退会の手続き）は**新項目が内容を包含する**ため非公開にした。

種別ごとに残したもの:

| | 個人 | 事業所 | 賛助 |
|---|---|---|---|
| | ■ 年会費について | ご連絡について | ■ 年会費について |
| | ■ 住所変更等の手続き | ■ 年会費について | ■ 介護支援専門員番号について |
| | | ■ 事業所内の専門員・住所の変更 | ■ 住所変更等の手続き |
| | | ■ 登録状況の確認について | |
| **項目数** | 4 → **2** | 6 → **4** | 5 → **3** |

住所変更を共通化しなかったのは、**事業所だけ内容が大きく異なる**ため（所属メンバーの変更を含む）。
事業所の「年度途中で人数が変わっても返還しない」は事業所固有なので共通へ移さず年会費の項目に残した。

## 3. 文面の方針（operator 決定）

協議会サイトの掲示文を起点に、次を調整した。

| 旧（紙の届出が前提） | 新 |
|---|---|
| 所定の「入会申込書」にて入会の意向を申出てください | **本フォームから入会の意向をお申し出ください** |
| 「変更届」に変更のあった項目を記入しご連絡ください | **変更のあった項目を本システムからお届けください** |
| ご連絡の上「退会届」を提出してください | **本システムから退会をお申し出ください** |

- **賛助会員は元の掲示文が無かったため新規に作成**した（個人会員の文面と `RD BR-01` に基づく）
- 事業所に「**所属する介護支援専門員（事業所メンバー）の変更は速やかに申し出る**」を追加
- 「変更・退会の手続き」に付いていた**外部リンクは引き継がない**。手続きが本システムで完結する以上、
  外部サイトへの導線は二重になるため

## 4. v376.76 で直したこと

**表示順の番号衝突。** v376.75 で追加した共通 3 項目に `1・2・3` を振ったが、既存の
「個人情報の利用目的」が**もともと 2 番**だったため、共通の並びに割り込んで表示されていた
（`■ 入会 → 個人情報 → ■ 会費 → ■ 退会`）。既存の採番を確認せずに振ったのが原因。

**確認チェックの文言。** 旧文言は「変更・退会手続き、退会期限、定款確認導線」と項目名を列挙していたが、
v376.75 の再編でこれらの項目が無くなり実態と合わなくなった。
**文面を変えても追随が要らない書き方**（「上記の注意事項（全体および会員種別ごと）を確認し…」）に変えた。

### 4.1 折りたたみの初期状態（v376.77）

v376.75 で折りたたみを入れた時点では、**読まれないままチェックされる懸念**から開いた状態にしていた。
実物を見て、共通項目だけでも縦に長く、**開いたままでは②全体が読み飛ばされやすい**と判断し、
初期状態を**閉じる**に変えた（operator 決定）。

開閉は `aria-expanded` を伴うボタンで、支援技術にも状態が伝わる。
