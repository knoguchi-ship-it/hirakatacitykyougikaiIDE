作成日: 2026-05-04

> 2026-05-04 追記: `v303` で旧 `adminDashboard` cache が `staffRows` なしで返る条件を追加修正し、admin split は `@63` が現行本番。現行正本は `docs/184_RELEASE_STATE_v303_2026-05-04.md`。

## 1. Scope

管理コンソールの会員管理 > 事業所会員ビューで、ダッシュボードカードには事業所職員数が表示される一方、一覧が 0 件になる不具合を修正した。

原因はデータソース不一致。カード集計は `getAdminDashboardData_()` が `T_事業所職員` を直接読み込んでいたが、一覧はフロントエンドの `members[].staff` から組み立てていた。管理コンソール初期表示では軽量な `getAdminInitData` / `getAdminDashboardData` を優先し、`fetchAllData` を呼ばないため `members[].staff` が未取得となり、条件に一致する職員が一切表示されなかった。

## 2. Fix

- `getAdminDashboardData_()` の返却値に `staffRows` を追加。
- `staffRows` は `T_事業所職員` の未削除行を正とし、親 `T_会員` から `officeName` / `officeNumber` を付与。
- フロントエンドの事業所職員一覧は `adminDashboardData.staffRows` を優先し、未提供時のみ従来の `members[].staff` に fallback。
- 職員詳細画面遷移時も、`members` 未取得の場合は一覧行の職員情報を fallback として使う。
