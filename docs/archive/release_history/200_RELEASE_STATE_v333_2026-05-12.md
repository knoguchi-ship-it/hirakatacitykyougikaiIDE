# Release State v333（活動報告 / 経費請求 2系統化）

作成日: 2026-05-11
本番反映日: 2026-05-12
状態: **Released**
対象: integrated/public、member split、admin split

## 1. 概要

役員の請求 UI を、従来の単一「請求」から **活動報告** と **経費請求** の 2 系統へ分離した。

- 活動報告: 活動部（組織）と業務分類を選択し、業務分類マスタの単価を請求金額として固定する。数量は常に 1。
- 経費請求: 活動部、請求内容、請求金額、添付ファイルを入力する。添付は必須。
- HEIC / HEIF は会員側ブラウザで JPG へ変換してからアップロードする。
- 管理者の請求管理コンソールでは、活動報告 / 経費請求をフィルタし、内容確認後に承認・却下できる。

## 2. DB / スキーマ変更

- `M_組織マスタ` に `全役員表示フラグ` を追加。
- `M_業務分類` を追加。
  - `業務分類コード`
  - `業務分類名`
  - `組織コード`
  - `単価`
  - `表示順`
  - `有効フラグ`
  - `削除フラグ`
  - `作成日時`
  - `更新日時`
- `T_請求` に以下を追加。
  - `請求種別`: `ACTIVITY_REPORT` / `EXPENSE_CLAIM`
  - `業務分類コード`
  - `単価`
  - `数量`

既存 `T_請求` レコードは読み取り時に `EXPENSE_CLAIM` として扱う。既存レコードへ添付必須を遡及適用しない。
