# Release State v336 — 2026-05-12

Status: deployed

## Scope

- 会員管理コンソール（会員一覧）と年会費管理コンソールのキーワード検索で、個人会員・賛助会員の **勤務先事業所名** でもヒットするようにした。
- 会員一覧フィルタを直書きの `String.includes` から、全コンソール共通の `matchesSearchQuery` に統一。
  - NFKC 正規化（全角/半角統一）
  - 大文字小文字無差別（Unicode case folding）
  - 半角/全角スペース完全除去マッチング（`枚方 介護` と `枚方介護` が同等）
  - 多語 AND マッチング
- バックエンドペイロード型を拡張:
  - `AdminDashboardMemberRow.officeName: string`
  - `AnnualFeeAdminRecord.officeName: string`
  - 値は `T_会員.勤務先名`。事業所会員=事業所名、個人/賛助会員=勤務先事業所名。
- プレースホルダー文言更新:
  - 会員管理: `会員番号・氏名・事業所名（勤務先含む）`
  - 年会費管理: `会員名・会員ID・事業所名（勤務先含む）・会員種別で検索`

## Why

ユーザー要求: 個人/賛助会員のキーワード検索で勤務先事業所名にもヒットさせる。スペース除去。全コンソールで同じ関数を使い回す。

Web 検索で確認した 2026 時点のグローバルベストプラクティス（Elasticsearch ICU normalizer / NFKC + case folding + whitespace handling）に既存 `matchesSearchQuery` が準拠していたため、新規アルゴリズム導入は不要と判断。共通関数の利用範囲を会員一覧にも広げる方針で統一性を確保した。
