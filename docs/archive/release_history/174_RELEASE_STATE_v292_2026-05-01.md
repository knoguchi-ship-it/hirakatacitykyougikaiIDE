# Release State v292

作成日: 2026-05-01
対象本番: `v292`

## 1. Scope

- `build-admin-gas.mjs` の `pruneUnreachableFunctionDeclarations` バグ修正。
  - 旧: `\b${name}\b` でマッチ → `ADMIN_ACTION_PERMISSIONS` 内の文字列キー `'getDbInfo'` / `'seedDemoData'` に誤マッチし変数宣言ごと削除
  - 新: `\b${name}\s*\(` でマッチ → 関数呼び出しのみを削除対象とし、データ宣言は保護
- `build-member-gas.mjs` の同一パターンを同時修正（member split で同様の誤削除が発生しうるため）。
- admin split artifact に `ADMIN_ACTION_PERMISSIONS` が復元された結果、`processApiRequest` が正常に動作するようになった。

## 2. Root Cause

v291 で `build-admin-gas.mjs` に `pruneUnreachableFunctionDeclarations` を初めて適用した際、
`removableTopLevelStatements` フィルタの正規表現 `\b${name}\b` が、
`ADMIN_ACTION_PERMISSIONS` オブジェクトリテラルの文字列キー（`'getDbInfo'`、`'seedDemoData'`）に誤マッチし、
変数宣言ごと削除してしまっていた。

削除された変数が参照されると `ReferenceError: ADMIN_ACTION_PERMISSIONS is not defined` が発生し、
`processApiRequest` が呼び出されるたびに全 API コールが失敗。
管理者ログイン（`checkAdminBySession`、`adminLoginWithData`）を含む全操作が不能になった。
