# Release State v306

作成日: 2026-05-06
対象版番: `v306`

## 1. Scope

管理コンソールの保存後バックグラウンド再読込で、member portal 用 action を呼び得る状態管理を修正した。

- 管理者ロールでは `refreshAllData()` から member portal 再読込を呼ばない。
- `loadAppData()` は管理者ロールで `memberPortalLoaded` を true にしない。
- 管理者ロールの保存後全体データ再読込を silent 扱いにし、バックグラウンド更新失敗で App 全体を `initError` に落とさない。
- 年会費コンソールに限らず、管理コンソール全体の保存後再読込で `unsupported_action` の全画面 fatal error が起きないようにした。

詳細: `docs/189_ADMIN_CONSOLE_REFRESH_UNSUPPORTED_ACTION_FIX_2026-05-05.md`
