名簿ビュー

  • 列: 連番・氏名・事業所・申込者区分・連絡先・申込日・申込状態・出欠状態 v360・事務局メモ v360（管理者専用）
  • 検索・絞り込み: 氏名/事業所/区分/出欠状態で絞り込み
  • 一括操作: 全員出席セット / 全員欠席セット
  • 個別操作: 行内ドロップダウンで出欠変更（即時保存）

申込者の管理者追加

  • 会員選択モーダル: 会員管理の検索 UI 流用。電話・紙申込の代理登録に対応
  • ゲスト枠: 会員未登録者を氏名・事業所・連絡先のみで追加。T_外部申込者 + T_研修申込.外部申込者ID で記録
  • キャンセル: 管理者が代理キャンセル可能（取消日時に手動記録）

出欠 5 状態（M_出欠状態 マスタ）

コード名称用途
UNRECORDED未記録既定値
PRESENT出席
ABSENT欠席
LATE遅刻
SAMEDAY_CANCEL当日キャンセル事前キャンセル（取消日時）と別扱い

受講履歴（会員詳細タブ・v360 新規）

会員管理コンソール → 会員詳細モーダルに「受講履歴」タブを追加。過去受講した研修・出欠状態・受講時所属を一覧表示。検索センタリック。

xlsx 出力

SheetJS（UMD bundle）で client-side 生成。会場受付名簿（A4 縦）/ 事務局保管用（全列詳細）の 2 種類。CSV (UTF-8 BOM) も併用可能。導入時罠回避: vite-plugin-singlefile 互換性は v351 ロールバック事例があるため、bundle 後の admin shell 起動テストを必須化。

📧一括メール送信（v360 拡張）

既存 TrainingMailSender（v316 〜）を拡張し、テンプレート流用・セグメント送信・送達ログ明細を追加。

テンプレートライブラリ（流用拡張）

既存の T_システム設定.ROSTER_TEMPLATE_LIST（v316〜）に category フィールドを追加して流用。新規テーブルは作らない。

  • TRAINING_REMINDER リマインダ
  • TRAINING_THANKS 開催後お礼
  • TRAINING_CANCEL キャンセル通知
  • MAILING_LIST 既存名簿出力テンプレ（移行互換）

セグメント送信

送信対象を以下の条件で絞り込み可能:

  • 申込者全員（既存）
  • 申込者区分（個人/賛助/職員/外部）
  • 出欠状態（未記録のみ / 出席者のみ / 欠席者のみ）
  • 事業所ごと
  • 個別選択（既存）

送達ログ（Header-Detail パターン）

既存 T_メール送信ログ（バッチサマリ）を Header として維持、新規 T_メール送信明細 を Detail として追加。誰にいつ何が届いたか・誰の送信が失敗したかを per-recipient 単位で記録。問合せ対応・監査の正本。

既存設計 T_支払い / T_支払い明細 と一貫した設計パターン。

差込変数（v360 拡張）

{{氏名}} {{事業所名}}（既存）+ {{研修名}} {{開催日}} {{会場}} {{参加費}}（v360 追加）
