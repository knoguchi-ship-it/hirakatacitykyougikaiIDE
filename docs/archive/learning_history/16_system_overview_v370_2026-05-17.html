変更申請ワークフロー（v368 + v369）

従来ハードコードだった「受付確認」「承認通知」「却下通知」メールを システム設定 9 キー に分離し、システム設定 UI から件名・本文・ON/OFF を編集可能に。

差込変数: {{氏名}} {{会員種別ラベル}} {{申請種別}} {{申請ID}} {{受付日時}} {{処理日時}} {{処理者名}} {{変更内容サマリー}} {{処理備考}}

{{変更内容サマリー}} は buildChangeSummaryText_ で「・メールアドレス: NEW」「・職員追加: 山田 太郎（CM 12345678）」等の人間可読リストに自動展開。

個人/賛助 → 事業所職員転籍時の代表メアド必須も緩和（CM 番号で紐づけるため）。
