# Release State v308

作成日: 2026-05-06
対象版番: `v308`

## 1. Scope

管理コンソールの会員詳細編集画面の年会費表示を、2024 年度以降を下限として、当年度から過去 4 年分まで表示するように修正した。

- 例: 当年度が 2026 年度の場合、2026 / 2025 / 2024 年度を表示する。
- 当年度が 2027 年度以降の場合は最大 4 年分を表示する。
- 年会費対象外年度は表示しない。
- 既存の年会費保存 API と DB スキーマは変更しない。

詳細: `docs/191_ADMIN_MEMBER_DETAIL_ANNUAL_FEE_EDIT_2026-05-06.md`
