# Release State v300

作成日: 2026-05-04
対象版番: `v300`

## 1. Scope

管理ポータルの会員管理コンソール内「事業所会員」ビューを、事業所単位の一覧から事業所職員単位の一覧へ修正した。

- 1行を1職員として表示する。
- 表示カラムを `事業所名 / 氏名 / カナ / メール / 区分 / 在籍状況` に変更した。
- `代表者` カラムと `操作` カラムは置かず、行クリックで既存の職員詳細へ遷移する。
- `氏名 / カナ / メール / 区分 / 在籍状況` は一覧上で編集できる。
- 保存ボタンは変更件数、保存中状態、成功/エラー通知を持つ一括保存 UI とした。
- 検索、フィルター、ページングでは新規 API を呼ばない。保存時のみ変更行に対して既存 `updateStaff` API を順次呼び出す。

## 5. Performance / Architecture Guardrail

- 追加 GAS API、DB schema 変更、認証境界変更はなし。
- 検索、フィルター、ページングは React state のみで完結。
- 保存時は dirty row のみ既存 `updateStaff` API を呼び出す。
- 保存前の必須値/メール形式検証で、明らかな入力エラー時は API を呼ばない。
- 代表者変更や除籍時の業務制約は既存 `updateStaff_` のサーバー側検証を正とする。
