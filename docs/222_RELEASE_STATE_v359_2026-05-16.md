# Release State v359

Date: 2026-05-16
Status: production deployed

## Scope

会員ログイン画面の待ち時間とパスワード再設定 UX を改善した。

- 会員ログインは `memberLoginWithData` を使わず、`memberLogin` で認証を先に完了する。
- 認証後、会員ポータルデータは既存の `getMemberPortalData` 遅延ロードで取得する。
- ログイン画面に `ログインIDを保存する` を追加した。保存対象はログインIDのみで、パスワードはアプリ独自保存しない。
- パスワード入力に表示/非表示トグルを追加した。
- `パスワードを忘れた方` から、`ログインID + 登録メールアドレス` による再設定手続きメール送信を追加した。
- 事業所職員アカウントの登録メール正本は `T_事業所職員.メールアドレス`。会員IDのみのアカウントは `T_会員.代表メールアドレス`。
- 再設定メールの送信元は既存の `CREDENTIAL_EMAIL_FROM`。
- 確認コードは 30 分有効、短期キャッシュに HMAC hash で保存、5 回失敗で破棄する。
- 再設定成功時に `T_認証アカウント` のパスワード hash / salt / 更新日時を更新し、ログイン失敗回数とロック状態をリセットする。

## Security Notes

- 登録有無やメール照合結果を画面応答で漏らさないよう、再設定メール送信要求の成功応答は共通文言に統一した。
- 平文パスワードはメール送信しない。
- 確認コードそのものは DB、ログ、ドキュメント、チャットに記録しない。
- パスワード再設定は member split の未認証 member action として許可し、public/admin boundary audit では境界外 action として扱う。
