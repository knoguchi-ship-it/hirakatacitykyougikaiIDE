# Release State v305

作成日: 2026-05-05
対象版番: `v305`

## 1. Scope

宛名リスト出力コンソールと関連検索ロジックを修正した。

- 年会費納入 `未納` の対象を、選択年度に会員だった人に限定した。
- 入会日・退会日を年度基準で判定し、年度内退会者は対象に含める。
- 年度開始前に退会済み、または年度終了後に入会した人は対象外にする。
- 年会費履歴がない場合の `UNPAID` 扱いは、年度内会員に限って適用する。
- 名簿出力も同じ年度基準 snapshot を使うようにした。
- 氏名検索を共通化し、氏名間の半角/全角スペース有無に依存せずヒットするようにした。
