# Release State v298

作成日: 2026-05-04
対象本番: `v298`

## 1. Scope

`v297` で既知化した BUG-001「振込口座管理タブで事業所職員役員の口座登録・確認ができない」を修正。

- 管理者ポータル `役員管理コンソール > 振込口座管理` の対象役員選択を、`会員ID` 固定ではなく `member:<会員ID>` / `staff:<職員ID>` の判別可能な key へ変更。
- 事業所職員型役員では `staffId` payload を `getAdminBankAccount` / `saveAdminBankAccount` / `deleteAdminBankAccount` へ渡す。
- 口座は人物単位のため、同一人物が複数役職を兼務しても選択肢を人物 key で重複排除。
- GAS バックエンドの `getBankAccount_` / `saveBankAccount_` / `deleteBankAccount_` は v297 時点で `staffId` 対応済みのため、DB スキーマ変更・GAS action 追加はなし。

## 5. Data Model Assessment

データモデル変更は不要。`T_役員` / `T_振込口座` / `T_請求` は `会員ID` と `職員ID` の XOR で人物を識別する現行方針を維持する。

今回の不具合は DB モデルではなく、管理 UI と TypeScript API 型が `memberId` 前提のまま残っていたことが原因。
