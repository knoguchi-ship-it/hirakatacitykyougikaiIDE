# 244. WCAG 2.2 AA Conformance Statement（適合声明・初版）

更新日: 2026-05-21
バージョン: v374 時点
適用範囲: 枚方市介護支援専門員連絡協議会 会員システム
レビューサイクル: **半年ごと** + 大規模 UI 改修時

## 1. 適合表明

本システムは **WCAG 2.2 Level AA に部分的に適合** することを目指して開発・運用されています。本初版時点では完全な適合 (full conformance) は宣言せず、**部分適合 (partial conformance)** を以下に示します。

## 2. 評価方法

### 2-1. 自動検証 (axe-core)

- ツール: `@axe-core/playwright` + `axe-core` (Deque Labs)
- 実行コマンド: `npm run test:a11y`
- WCAG タグ: `wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa, best-practice`
- 対象 view (公開ポータル, v374 baseline):
  - home（カードメニュー）
  - memberApplication（新規入会申込フォーム）
  - noticeDialog（事務局からのお願いモーダル）
- レポート: `.test-out/a11y-report.md` / `.test-out/a11y-report.json`
- CI gate: `CI=1 npm run test:a11y` で critical / serious が 1 件でも見つかれば exit 1

### 2-2. レスポンシブ + タップターゲット検証 (Playwright)

- 7 viewport（320 - 1920px）× 3 view を網羅
- `npm run test:responsive` (公開ポータル) / `:admin` / `:member`
- タップターゲット: 24px (fail) / 44px (warn)
- 横スクロール: `scrollWidth > clientWidth + 1` で fail
- WCAG 2.2 §1.4.10 Reflow / §2.5.5 Target Size 準拠

### 2-3. 手動検証 (operator + 開発者)

- キーボードのみ操作（Tab / Shift+Tab / Enter / Space / ↑↓ / ESC）
- スクリーンリーダー読上げ（NVDA + Chrome / VoiceOver + Safari）
- フォーカストラップ（モーダル / dialog で適切に閉じ込められるか）
- フォーカスリターン（モーダル閉鎖後、起動元要素へ戻るか）
- エラーサマリー（フォームエラーから各項目へジャンプできるか）
- 認知負荷（ジャーゴン回避・読みやすさ・段階的開示）

## 5. 既知の限界と免責

- **GAS iframe 内描画**: アプリは `script.googleusercontent.com` の二重 iframe 内で動作。axe-core は frame 内に inject すれば動作するが、frame タイミングによる incomplete (axe が判定不能) が 3 件発生。これらは manual で確認必要。
- **動的フォーム検証**: 「研修申込」「変更申請」など多段フォームの全 path は自動スキャン対象外（trigger 自動化が複雑）。
- **管理者ポータル / 会員マイページ**: storageState が必要なため CI 自動化は除外。`npm run test:responsive:admin` / `:member` を operator が実施。
