# Release State v334（役員管理の状態編集 / 読み込み高速化）

作成日: 2026-05-12
本番反映日: 2026-05-12
状態: **Released**
対象: admin split（役員管理）

## 1. 背景

役員管理ページで以下の要件を受けた。

- 役員の紐づけ変更だけでなく、状態を任意に変更できるようにする。
- 就任日の表示から時刻を除く。
- 役員管理ページ、および全体の読み込みが遅くなった原因を調査する。

## 2. 原因

役員管理ページ表示時に、役員管理に不要な汎用 `fetchAllData` が App 側から走る構造になっていた。さらに役員管理コンポーネント内でも `getOfficerMasterData` と `getOfficerManagementData` を別々に呼び、マスタ系と役員管理系の取得が重複していた。

Apps Script では Sheets など外部サービス呼び出しの削減、読み書きのバッチ化、必要データだけの取得、キャッシュ活用が性能上重要であるため、役員管理専用 API 1 回で画面に必要なデータを返す構成へ変更した。

## 3. 実装

- `getOfficerManagementData_()` が `organizations`、`roles`、`officers`、`candidates` をまとめて返すように変更。
- 役員管理ページで `fetchAllData` を自動実行しないようにした。
- 役員管理ページで `getOfficerMasterData` を追加呼び出ししないようにした。
- `就任日` / `退任日` は `YYYY-MM-DD` に正規化して返すようにした。
- `updateOfficerRecord` を admin API に追加し、役職、就任日、退任日、備考を編集可能にした。
- 状態変更 UI を追加し、現職 / 退任済みを任意に切り替えられるようにした。
- 現職へ戻す場合は退任日を空にする。退任済みにする場合は退任日を必須にする。
- 同一担当者・同一役職で現職レコードが重複しないようサーバー側で検証する。
