## 4. Security Notes

- `PASSWORD_HASH_PEPPER_V1` は 3 project すべてに設定済み。
- pepper の値は Git、docs、handover、logs、chat、生成物へ記録していない。
- Apps Script UI で設定するために一時利用した browser localStorage は削除済み。
- 一時 setter 関数は最終 artifact へ残していない。`rg "__setPasswordHashPepperV1ForRelease_" backend/Code.gs gas/member/Code.gs gas/admin/Code.gs gas-src/Code.full.gs` は該当なし。
- `.env` は Apps Script 本番 runtime の正本にしない。ローカル補助に使う場合も未コミット・未記録を維持する。
