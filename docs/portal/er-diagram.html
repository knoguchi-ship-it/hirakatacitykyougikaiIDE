更新方法

スキーマ変更（テーブル定義 / カラム追加 / 列順変更）を行った際は:

  1. gas-src/Code.full.gs の テーブル定義 を更新
  2. docs/03_DATA_MODEL.md の Mermaid ER 図ブロックを同期
