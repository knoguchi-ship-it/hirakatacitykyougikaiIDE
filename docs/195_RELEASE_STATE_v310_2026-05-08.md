# Release State v310

作成日: 2026-05-08
対象版番: `v310`

## 1. Scope

宛名リスト出力コンソールの年会費納入フィルターを、単一ドロップダウンから「年度別・複数条件 AND ビルダー」へ刷新した。

- 「+ 条件を追加」ボタンで [年度▼] [状態▼] [×] 行を無制限に追加可能。
- 複数条件はすべて AND で評価（例: 2026年度:未納 AND 2025年度:未納 の会員のみ表示）。
- 年度選択肢は右上「年度フィルター」と同じ `years` リストを使用（DB の年会費履歴から自動算出）。
- 納入履歴レコードが存在しない年度は「未納」として扱う（既存動作と統一）。
- アクティブフィルタータグは条件ごとに個別表示・個別削除。

## 6. Operator Verification Pending

実ブラウザ確認は操作者側で実施する。

- 宛名リスト出力コンソールの絞り込みフィルターに「年会費納入（年度別）」セクションが表示されること。
- 「+ 条件を追加」で行が追加され、年度と状態を選択できること。
- 例: [2026年度: 未納] と [2025年度: 未納] の2条件を追加すると、両年度とも未納の会員のみ絞り込まれること。
- アクティブフィルタータグが条件ごとに「年会費 2026年度: 未納 ×」形式で表示されること。
- タグの × をクリックするとその条件のみ解除されること。
- 「すべてリセット」で全条件がクリアされること。
- 既存の種別・状態・郵送先・住所不備フィルターが引き続き正常に動作すること。
