## 0. 検査の方法

仕様書の記述のうち**検証可能な言明**（数値・列名・関数名・許可リスト・フロー・禁止事項）を抽出し、
実装（`gas-src` / `src` / build スクリプト / 生成物）と突合する。根拠は必ず `file:line` で示す。
「たぶん合っている」は書かない。確認していない項目は「未検査」と明記する。

**差分の種類**: ①実装が古い ②仕様が古い ③どちらとも取れる（曖昧） ④仕様に記載なし（暗黙仕様） ⑤置き場所が誤り
**重要度**: 🔴 実害あり（会員・事務局に見える） / 🟡 内部不整合 / ⚪ 表記ゆれ

## 5. 技術要件に関する operator 判定（Step 3・2026-09-03）

出典はすべて 2026-09-03 に公式ドキュメントから取得した値。再取得を避けるため数値をここに固定する。

### T-01 CacheService の設計予算 — **確定**

**公式（Apps Script Cache Service リファレンス）**: 1 キー 100 KB / キー名 250 文字 / TTL 1〜21,600 秒（既定 600 秒）。
**合計サイズ上限は記載なし**。ただし **件数上限 1,000 件**があり、超過時は「**有効期限が最も遠い 900 件を残す**」＝
古い順ではなく**期限が近いものから捨てられる**。

| 項目 | 確定値 | 根拠 |
|---|---|---|
| 総キー数 | **200 キー以内**（公式上限 1,000 の 20%） | エビクション発生まで 5 倍の余裕 |
| 総サイズ | **1.5 MB 以内** | 現状実測 約 500 KB の 3 倍を許容 |
| 1 キー | **90 KB**（現行維持） | 公式 100 KB に対し 10% マージン |
| TTL | **300 秒**（現行維持） | 書込時 invalidation があるため長期保持は不要。長い TTL は件数滞留を招く |

**設計原則**: CacheService は**消えてもよい前提でのみ使う**。合計サイズの保証が無く 1,000 件超で予告なく捨てられるため、
**キャッシュミス時に必ず DB から再構築できること**を必須とする（現行実装は充足）。追加課金は発生しない（Apps Script の機能）。

### T-02 メール添付の上限 — **確定**

**公式（Gmail ヘルプ）**: 送信上限は **25 MB**（個人アカウント。**Workspace は管理者が設定値を決定**）。
超過時は「**Gmail が添付を外して Drive リンクに置き換える**」。エンコードによる増加の記載は**なし**。

| 項目 | 確定値 | 理由 |
|---|---|---|
| 1 通の添付合計 | **20 MB を超えたらアプリ側でエラー**（送信しない） | base64 で実サイズが約 1.33 倍になるため、25 MB 枠に収めるには 20 MB が安全側 |
| 1 ファイル | 10 MB（現行維持） | 既存実装と揃える |
| 超過時 | **送信前に止める**（Drive リンク自動置換に委ねない） | 置換されると会員には Drive リンクが届き、共有設定次第で**開けない**事故になる |

→ Workspace の実際の管理者設定値は未確認のため **G-15** を新設。

### T-03 GCP を ¥0 で維持する前提 — **条件付きで確定（再評価タスクつき）**

**公式（Google Cloud Free Tier・Firebase Firestore Quotas）**:

| サービス | 無料枠 | 地域条件 |
|---|---|---|
| Firestore | 読取 50,000/日・書込 20,000/日・削除 20,000/日・保存 1 GiB・下り 10 GiB/月（いずれもプロジェクト単位） | 記載なし。**無料は 1 プロジェクトにつき 1 データベースのみ** |
| Cloud Run | 200 万リクエスト/月・360,000 GB 秒・180,000 vCPU 秒 | **下りの無料 1 GB/月は「北米からのみ」＝ asia-northeast1 は対象外** |
| Cloud Storage | 5 GB 月・Class A 5,000/月・Class B 50,000/月 | **`us-east1` / `us-west1` / `us-central1` のみ**。**東京リージョンは無料枠の対象外** |
| Secret Manager | アクティブシークレット 6 版/月・アクセス 10,000 回/月 | — |
| Pub/Sub | 10 GiB/月 | — |

**判定**: 現行規模（会員 222・職員 157）では Firestore / Cloud Run の**計算・保存は無料枠に十分収まる**。
ただし**下り通信と Cloud Storage の地域条件**が ¥0 維持の実質的な制約になる。

**¥0 維持のための制約（TRD に記載する）**:
1. 静的アセットは **Firebase Hosting** から配信し、Cloud Run からは**返さない**（Cloud Run の下りは東京では無料枠外）
2. Cloud Run は **JSON API のみ**を返す（1 応答を数 KB〜数十 KB に抑える）
3. **Firestore は 1 プロジェクト 1 データベース**（検証用に 2 つ目を作ると課金対象）
4. 添付ファイルを Cloud Storage へ移す場合、**東京リージョンは無料枠対象外**。容量課金（数 GB なら月数十円規模）を許容するか、
   Drive を継続するかの判断が要る
5. 既存ガードを維持: max-instances=1 / 予算アラート / **予算超過の自動停止 killswitch**（実装済み・実イベント受信を実測済み）

**→ operator 指示（2026-09-03）: 「本当に今の仕様を GCP でも満たせるのか」の再評価が必要。G-16 を新設。**

### T-04 ログイン失敗の時限解除 — **確定（実装は別リリース）**

現行は 5 回失敗で**無期限ロック**。loginId が介護支援専門員番号で推測可能なため、
第三者が故意に他人のアカウントをロックできる状態にある。

**確定仕様（2026-09-03 operator）**: **連続失敗でカウントし、認証成功した時点でカウントを 0 に戻す。**

| # | 項目 | 仕様 |
|---|---|---|
| 1 | カウント対象 | **連続した**認証失敗のみ。**成功した時点で失敗回数・ロック状態・解除予定日時をすべて 0/解除にリセット** |
| 2 | 段階的な待機 | 連続 3 回目 → 1 分、4 回目 → 5 分、5 回目 → 15 分、6 回目以降 → 60 分（上限） |
| 3 | 自動解除 | `ロック解除予定日時` を過ぎたら自動解除し、失敗回数を 0 に戻す |
| 4 | 恒久ロック | **連続 20 回**失敗で管理者解除が必要な恒久ロックへ移行（成功すれば 0 に戻るため、正当な利用者は到達しない） |
| 5 | 管理者解除 | 管理画面から即時解除（現行機能を維持）。監査ログに記録 |
| 6 | エラー文言 | 「ログイン ID またはパスワードが正しくありません」で統一。**ロック中も同一文言**（ロック状態を攻撃者に教えない） |
| 7 | 例外 | ロック中は正しいパスワードでも解除しない（待機時間の短縮を許さない） |
| 8 | ログ | 失敗・ロック・自動解除・管理者解除を `T_ログイン履歴` に記録（GAS では IP を取得できないため記録しない） |

**必要な変更**: `T_認証アカウント` に **`ロック解除予定日時`** を 1 列追加／閾値・待機時間を共有モジュールへ集約
（現在 `>= 5` が 2 箇所にベタ書き＝`AGENTS.md` §3 違反）／unit test ＋ 実 DB dryRun ／会員ログイン画面の案内文言。

**実装は仕様書の巻き直しとは別リリースで行う**（本 Step では仕様の確定のみ）。

**GCP 移植性**: `ロック解除予定日時` は単なるタイムスタンプ列で Firestore のフィールドへそのまま移せる。
判定は時刻比較のみで GAS 固有機能に依存しない。GCP の member-auth（Cloud Run）には同種の防御層が実装済みのため、
移行時に仕様を突き合わせる。**NG パターン非該当**。

### T-05 リージョン方針 — **確定: 全リソースを東京（asia-northeast1）に固定**

**背景（operator 指摘・2026-09-03）**: Google Workspace のデータリージョンは
**`United States` / `Europe` / `No Preference` の 3 択のみで日本を選べない**（公式で確認）。
対象エディションにも Business Starter は含まれず、Nonprofits 版では機能自体が使えない可能性がある（G-23）。
したがって**現行のスプレッドシート DB は米国または欧州にあり、日本国内保管を満たしていない**。

**GCP は東京を明示指定でき、追加費用も発生しない**（Firestore・Cloud Run の無料枠にリージョン制限は無い）。
すなわち国内保管を要件にするなら、**GCP 移行が唯一の実現手段**である。

#### 実測（2026-09-03・`gcloud` による読み取りのみ。課金対象の操作なし）

| リソース | 実測値 |
|---|---|
| Firestore | `projects/hcmn-member-system-prod/databases/(default)` / **`asia-northeast1`** / FIRESTORE_NATIVE。**無料枠が適用される `(default)`**。ロケーションは作成後変更不可のため、**作り直しは不要** |
| Cloud Run | `hcmn-portal-api` / `hcmn-member-auth` / `hcmn-member-api` / `hcmn-password-hash` / `hcmn-billing-killswitch` の **5 サービスすべて `asia-northeast1`** |
| Cloud Storage | **業務用バケットは存在しない**。GCP が自動作成した内部用 3 本のみ（`run-sources-…` 13.15 MiB / `gcf-v2-*` 2.74 KiB、いずれも東京）＝月 0.05 円相当 |
| 予算 | `hcmn-phase0-alert` **月 500 円（JPY）** で稼働中 |

**確定事項**: 新規に作る GCP リソースは**すべて `asia-northeast1`**とする。
Firebase Hosting はリージョンの概念を持たない CDN 配信のため対象外だが、**個人データを置かない**（静的アセットのみ）。

### T-06 Cloud Storage — **凍結（現時点では採用しない）**

**operator 判断（2026-09-03）: 現状は凍結。添付ファイルは Google Drive を継続する。**
将来必要になった場合の判断材料として、**取得済みの実単価を本節に残す**（再調査を不要にするため）。

#### 東京（asia-northeast1）の実単価

Google **Cloud Billing Catalog API** から取得（2026-09-03・JPY 建て・**推定値ではなく課金アカウントに紐づく実価格**）。

| 項目 | SKU 名 | 単価（JPY） |
|---|---|---|
| Standard 保存 | `Standard Storage Tokyo` | **3.665625 / GiB・月** |
| Class A 操作（書込・一覧） | `Regional Standard Class A Operations` | **0.00079687 / 回**（1 万回 ≈ 8 円） |
| Class B 操作（読取） | `Regional Standard Class B Operations` | **0.00006375 / 回**（1 万回 ≈ 0.6 円） |
| 下り（アジア向け） | `Download APAC` | **19.125 / GiB**（〜10 TiB）／17.53（次段）／12.75（大量時） |

**無料枠は `us-east1` / `us-west1` / `us-central1` のみ**。東京は **1 GB 目から課金**される。

#### 費用の算出式と試算

```
月額 = 保存GiB × 3.665625
     + ダウンロードGiB × 19.125     ← 費用の 8 割以上を占める
     + 書込回数 × 0.00079687
     + 読取回数 × 0.00006375
```

| シナリオ | 保存 | 月間ダウンロード | 操作 | 月額 | 年額 |
|---|---|---|---|---|---|
| 小（研修案内 PDF 数件＋請求添付） | 1 GiB | 0.5 GiB | 500 / 5,000 | **約 14 円** | 約 170 円 |
| 中（数年分の蓄積・会員が資料を閲覧） | 5 GiB | 5 GiB | 2,000 / 20,000 | **約 117 円** | 約 1,400 円 |
| 大（画像添付が増える） | 20 GiB | 20 GiB | 5,000 / 50,000 | **約 463 円** | 約 5,600 円 |

**参考**: 2 MB の研修案内 PDF を会員 222 名が閲覧すると 1 研修あたり約 0.44 GiB ＝ **約 8.4 円**。
大シナリオ（月 463 円）は予算アラート 500 円/月にぎりぎり収まる水準。

#### 採用しなかった理由（凍結の根拠）

1. Drive 継続なら **¥0**（Workspace 契約に含まれ、**下り課金も無い**）
2. 既存ファイルの移行と URL 書き換えが**不要**
3. Drive の共有設定に依存した権限制御を**していない**ことは確認済みで、**将来 Cloud Storage へ移す余地は残る**
4. 米国リージョン（無料枠あり）は**個人データの国外保管**となり、T-05 のリージョン方針と矛盾するため除外
